## Rutas fuera de las 17 pantallas objetivo

`/login`, `/registro`, `/verificar-email`, `/olvide-contrasena`, `/restablecer-contrasena`, `/invitacion`, `/precios`, `/terminos`, `/privacidad`, `/t/:token` y `/profile` se mantienen dentro de sus componentes existentes. No forman parte de los 17 flujos operativos pedidos; sus rutas y flujos de autenticación/públicos no deben romperse.

## Condición de verificación

La matriz describe integración declarada por tipos/adaptadores. Para afirmar funcionamiento real se requiere ejecutar CI y, para acciones de negocio, un entorno de pruebas aislado con autorización. No se hizo petición remota durante esta auditoría.
